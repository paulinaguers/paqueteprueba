# Viñeta del paquete de prueba

``` r

library(paqueteprueba)
```

Esta es una viñeta de prueba. Podemos mostrar cómo usar la función
[`suma()`](https://paulinaguers.github.io/paqueteprueba/reference/suma.md):

``` r

suma(2,2)
#> [1] 4
```

Luego tenemos la función
[`inches_to_cm()`](https://paulinaguers.github.io/paqueteprueba/reference/inches_to_cm.md):

``` r

inches_to_cm(5)
#> [1] 12.7
inches_to_cm(10)
#> [1] 25.4
```
